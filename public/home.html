Share Files

Send files to a friend over a private link. WebRTC carries the bytes peer-to-peer — nothing is stored on a server.

Receive files

Enter the session code you were given.

A session code is 3–24 characters: a–z, 0–9, - or _.

How it works

  1. The sender picks files and shares the link (or the QR code) with the receiver.
  2. The bytes travel directly between the two browsers over a WebRTC DataChannel. The server only helps set up the connection — it never sees or stores your files.
  3. Both sides must be online at the same time. Closing the sender's tab ends the transfer.

What it needs

  • A current browser (Chrome, Edge, Firefox or Safari).
  • A secure address (HTTPS) — this page already uses HTTPS.
  • There is no relay server (TURN), so both sides must connect directly. Strict NAT or corporate firewalls can block it; IPv6 helps.
  • Nothing is persisted: no account, no database, no files kept after both tabs close.
